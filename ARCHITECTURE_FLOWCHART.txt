Diagram C: Filtering Methods and File Conversion

flowchart LR
  IN[Input File]
  TYPE{File Type}

  CSV[CSV]
  JSON[JSON]
  XLSX[Excel]
  MD[Markdown Table]

  PREP[Unified Table Representation]
  FILT[Filtering Layer]

  F1[Equality Filter\ncolumn = value]
  F2[Contains Filter\ntext contains]
  F3[Range Filter\nmin <= value <= max]
  F4[Rule Combination\nAND / OR]

  CLEAN[Cleaned Dataset]
  CONV{Output Format}
  OCSV[CSV Output]
  OJSON[JSON Output]

  IN --> TYPE
  TYPE --> CSV --> PREP
  TYPE --> JSON --> PREP
  TYPE --> XLSX --> PREP
  TYPE --> MD --> PREP

  PREP --> FILT
  FILT --> F1
  FILT --> F2
  FILT --> F3
  FILT --> F4

  F1 --> CLEAN
  F2 --> CLEAN
  F3 --> CLEAN
  F4 --> CLEAN

  CLEAN --> CONV
  CONV --> OCSV
  CONV --> OJSON
